Code Self Study — homepage mockups

Standalone design directions for the homepage. Each file is pure HTML/CSS with no build step. Open any one to preview. The newest set (69–73) modernizes the current live design — Poppins + Inter + JetBrains Mono, a normal reading measure — and each carries a floating design panel for live light/dark, palette, font, radius, and density switching.
